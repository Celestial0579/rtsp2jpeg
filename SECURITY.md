# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste Version (siehe [Releases](https://github.com/Celestial0579/rtsp2jpeg/releases/latest)). Ältere Versionen werden nicht gepflegt.

## Sicherheitslücke melden

Bitte melde Sicherheitslücken **vertraulich** über den Reiter „Security“ des Repositorys: [Sicherheitslücke melden](https://github.com/Celestial0579/rtsp2jpeg/security/advisories/new).

Eröffne dafür **kein öffentliches Issue** und poste keine Einzelheiten in Diskussionen oder Pull Requests.

## Was die Meldung enthalten sollte

- betroffene Version
- Schritte, um das Problem nachzustellen
- Auswirkung (was kann ein Angreifer erreichen?)

## Was danach passiert

Die Meldung wird geprüft. Wird die Lücke bestätigt, erscheint eine korrigierte Version; sie wird über ein Release und eine Sicherheitsmeldung (Security Advisory) bekanntgegeben.
